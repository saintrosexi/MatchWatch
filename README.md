# MatchWatch 🎬

> **Кино на двоих** — современный мультиплатформенный сервис для персонального и совместного выбора фильмов, сериалов и аниме.

![MatchWatch Studio & Mobile TMA](public/logo.png)

---

## ✨ Ключевые возможности

- 🎭 **Персональная 5D-лента свайпов**: Интеллектуальный рекомендательный движок на основе 5D-векторов эмоций (энергия, мрак, интеллект, эмоциональность, динамизм) и кинематографических настроений (Cine-Moods).
- 🎬 **Глубокий структурированный каталог (849 тайтлов)**:
  - **440 фильмов** мирового кинематографа
  - **262 культовых сериала**
  - **147 шедевров японской анимации (аниме)**
  - 100% рабочие постеры высокого разрешения через каскадный Кинопоиск HD CDN.
- ⭐ **Звёзды кино (Star Hub)**:
  - Профили 270 культовых актёров с проверенными фотографиями высокого разрешения, фактами биографии и фильмографиями.
  - Мгновенная генерация колоды свайпов только с выбранным актёром.
- 🔥 **Совместные комнаты в реальном времени (Realtime Rooms)**:
  - Создание комнат с 4-значным кодом и поддержка перехода по прямым ссылкам (`?room=CODE` или Telegram `start_param`).
  - Синхронизация присутствия участников и автоматический расчёт **компромиссного вкусового вектора** колоды.
  - Моментальное празднование совпадения (**Match Celebration**) с конфетти, победными фанфарами и тактильным откликом при обоюдном лайке.
- 🎰 **Кино-рулетка со слот-машиной**: Случайный выбор кино для спонтанных киновечеров.
- 💎 **Двойной адаптивный интерфейс (Dual Viewport Architecture)**:
  - **Desktop Cinema Studio**: Премиальный десктопный интерфейс для ПК и ноутбуков с боковой панелью, амбиентным свечением и полноэкранным кинотеатром.
  - **Mobile TMA Shell**: Нативный интерфейс для Telegram Mini Apps и мобильных браузеров с плавающим доком, тактильным откликом и жестовым свайпом карточек.

## 🛠 Стек технологий

- **Фронтенд**: React 19, Vite, Vanilla OLED CSS Design System (OLED black palette, neon coral/gold accents).
- **Иконки & Анимации**: Lucide React, Canvas Confetti.
- **Бэкенд & Realtime**: Firebase Realtime Database + Firebase Authentication.
- **Интеграция**: Telegram TMA WebApp SDK, Web Audio API, Web Vibration API.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка переменных окружения
Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

### 3. Запуск локального сервера разработки
```bash
npm run dev
```
Приложение откроется по адресу `http://localhost:5173/`.

### 4. Сборка для продакшена
```bash
npm run build
```

### 5. Запуск тестов
```bash
node scripts/run_e2e_tests.mjs
```

## 🧪 Тестирование и верификация

Проект снабжён 4-уровневой автоматизированной тестовой средой (203 E2E-теста):
1. **Tier 1: Feature Coverage (F1–F18)** — валидация категоризации, Kinopoisk ID, постеров, Star Hub, Firebase, комнат и сборки.
2. **Tier 2: Boundary & Corner Cases** — экстремальные значения, null-проверки, невалидные коды комнат, устойчивость к оффлайну.
3. **Tier 3: Cross-Feature Interactions** — сквозные интеграционные связи между фильтрами, комнатами и каталогом.
4. **Tier 4: Real-World Workflows** — полные пользовательские сценарии и синхронизация между устройствами.
